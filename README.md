## Lost works — do you have one?

The works below survive only as a title and a byline. The originals were lost in
the moves between hosts over the years. If you have a copy, or know where one
was posted (an old guild site, a forum, a saved page, a printout), please
[open an issue here](https://github.com/eriscorp/candle/issues/new). Even a lead helps:
a URL where it used to live is often enough to find it in the Wayback Machine.
