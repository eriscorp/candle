# Events of Temuair

An archive of the in-game **Events of Temuair** bulletin board — the board where Aislings post festivals, contests, recognitions, patch notes, and assorted Temuairan happenings.

This snapshot holds **419 posts**, captured 2026-07-18. Dates are the in-game **Moon / Sun** calendar (the *Nth Moon* is the month, the *Nth Sun* the day) — they are not real-world dates and do not run in order. Posts below are listed newest first, by board post number.

Each post's body preserves its original Dark Ages formatting and colors. On GitHub the colors are stripped and only the text shows; in a color-aware reader the posts appear as they did in-game.
