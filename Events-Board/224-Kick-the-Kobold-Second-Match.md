# Kick the Kobold - Second Match

_Posted by Mundane Gossip — 3rd Moon, 29th Sun · Post #224_

<pre style="background:#12100c; color:#e8e0cc; padding:1em; border-radius:6px; white-space:pre-wrap; font-family:monospace;">
The second match will begin shortly.  There have been so many requests to have the match public that the following changes have been made in order to accomodate:

- A series of skulls have been placed around the outside of the ring which should help to prevent outside interference into the game.  However, this has narrowed the viewing area.  I ask that everyone please walk as far as they can to the other side of the ring to make room for others entering.

- A spell will be cast so that talking will be prohibited just before the game begins.  This is to stop distractions from the participants and allow them to concentrate solely on the game at hand.

- The Kobolds have been given 100 times their previous vitality - hopefully stopping them from dying off too soon.

- Again, two kobolds will be first introduced into the game. If the game is going slowly or unproductively, a third will be added.

- Four hostesses have been put in each corner of the ring in order to allow those watching easy access to leave the arena.

Thank you all for your time and help in making this sporting event one that all can enjoy.  With these changes, it might be possible that the game will remain for other Aislings to enjoy after the Light and Chaos contest is over.

Eduardo
Burgess of Rucesion
