What is a memory contest?
~~~~~~~~~~~~~~~~~~~~~~~~~

(( Memories are in-game screenshots. The main method of taking an in-game screenshot is pressing the F12 key. 

Once a special category of the original Dark Ages contest system (with the highest possible award being Village), the last original memory recognitions were made in 2001, after which the category became defunct. While it was active, the memory category saw many memorable moments of early Temuair captured, with a great many ending up in the official Dark Ages website's screenshot section.
In 2025 the memory category was revived by the Mileth College as a special yearly contest. ))
